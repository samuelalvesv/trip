# Prioridade às Web APIs Nativas e Caminho Único Sem Fallbacks

A aplicação implementa estado derivado diretamente em React 19, validação de fronteira (*Fail First*), cálculo de proximidade por GPS (`navigator.geolocation` + fórmula de Haversine), geração de `.ics`, compartilhamento de arquivos (`navigator.share`), manipulação de área de transferência e compressão binária (`CompressionStream` / `DecompressionStream` com `deflate-raw`) diretamente sobre Web APIs nativas, sem bibliotecas externas de gerenciamento de estado, validação de schema ou formatação de datas. As únicas bibliotecas auxiliares de runtime são `qrcode` (geração offline da matriz óptica) e `jsqr` (decodificador único e determinístico de QR Code sobre `<canvas>`), seguidas de `vite-plugin-pwa` em tempo de build, evitando ramificações de fallback silencioso em prol de falha imediata (*Fail Fast*) com feedback explícito ao usuário.
