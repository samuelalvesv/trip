# Triage Labels

As skills operam com cinco papéis canônicos de triagem. Este arquivo mapeia esses papéis para as strings de rótulos utilizadas no issue tracker deste repositório.

| Label in mattpocock/skills | Label in our tracker | Significado                                                |
| -------------------------- | -------------------- | ---------------------------------------------------------- |
| `needs-triage`             | `needs-triage`       | Mantenedor precisa avaliar esta issue                      |
| `needs-info`               | `needs-info`         | Aguardando mais informações do autor                       |
| `ready-for-agent`          | `ready-for-agent`    | Totalmente especificada, pronta para execução pelo agente  |
| `ready-for-human`          | `ready-for-human`    | Requer implementação humana                                |
| `wontfix`                  | `wontfix`            | Não será implementada                                      |

Quando uma skill mencionar um papel (ex.: "apply the AFK-ready triage label"), utilize a string correspondente da coluna "Label in our tracker".

Edite a coluna "Label in our tracker" caso deseje adaptar o vocabulário.
